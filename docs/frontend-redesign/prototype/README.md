## 三个视图

| 视图 | 内容 |
|------|------|
| **落地页** | 导航 + Hero + 流向动画 + 8 特性卡 + 工作原理 + 快速开始 + 页脚 |
| **仪表盘** | 侧栏（搜索/折叠/移动端抽屉）+ 顶栏 + 4 KPI(含 sparkline) + 趋势图 + 甜甜圈图 + 渠道拓扑(含健康条) + 活动时间轴(含 rail) |
| **登录** | 品牌面板 + 登录表单 |

## 控制栏

- **视图切换**：落地页 / 仪表盘 / 登录
- **装饰档位**：丰富（全动效）/ 克制（降级）
- **主题**：暗色 / 亮色

## v2 改进

详见 `../AUDIT.md`。主要修复：

- 系统化间距/字号/动效标度（消除全部硬编码）
- WCAG AA 对比度验证（`--text-subtle` 3.8→4.6:1）
- 流向节点全改 SVG 图标（统一视觉体系）
- 侧栏激活指示条 + 移动端抽屉
- 活动时间轴 rail + 渠道健康条
- 主题感知 SVG 图表（切主题重画）
- 完整 a11y：aria-selected、sr-only 状态文字、SVG title/desc、焦点管理
- 新增登录视图 + Toast 反馈
- Timer 泄漏修复
