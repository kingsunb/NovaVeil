# Agent Note: 日志缓存命中保留数量，移除百分比

Status: implemented

## 问题

日志 Tokens 列与详情汇总此前显示 `缓存 N (xx%)`，例如 `57,872 / 55 / 缓存 55,296 (95.5%)`。百分比让本已拥挤的令牌列更窄，输出速度也被挤到第二行；排障需要知道命中量，但不需要百分比。

## 决定

`web-next/src/pages/Logs.tsx` 的 `CacheSuffix` 渲染 `" / 缓存 "` + 命中量（如 `缓存 55,296`），不再显示百分比。列表与详情共用该组件；无缓存仍返回 `null`。删除只为百分比服务的 `cacheRateOf` 与 `formatPercent`。

## 备选方案

- **保留百分比**：最强论据是保留原有观测信息；否掉因为百分比是派生值，命中量与输入 token 已能自行估算，且挤占列宽。
- **只显示「/ 缓存」标记**：最强论据是列最简洁；否掉因为排障时仍需要命中量，用户明确要求保留数量。
- **改用图标表示缓存**：最强论据是视觉更轻；否掉因为图标语义不直观，还要新增可访问标签与图标选择成本。

## 后果

日志列更紧凑，命中量仍可一眼看到，百分比不再出现。旧笔记的命中率百分比方案被本篇取代，其余实时观测决定（500ms 刷新、流式 c/s）仍有效。

## 验证

`web-next/src/pages/Logs.test.tsx` 覆盖：有缓存时显示 `/ 缓存 30`、不显示 `(29.7%)`；无缓存时无标记。

本仓库禁止 AI 执行构建与测试，以下命令由用户执行：

```sh

cd web-next && pnpm typecheck && pnpm lint

```
