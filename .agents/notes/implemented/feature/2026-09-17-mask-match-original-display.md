# Agent Note: 日志命中明细下发命中原文片段（翻转不下发原文决策）

Status: implemented

## 问题

上一篇 [日志详情展示脱敏命中明细](./2026-09-15-log-detail-mask-match-detail.md) 落地时，按数据最小化原则收紧为「完全不展示 original」：`MaskMatch` 只携带 `{Label, Placeholder}`，SSE 下发与 ErrorLog 持久化天然不含原文，即使前端被改也无法展示。当时的重访信号已写明：若审计频繁需要"从日志直接看命中原文"，应单独立项安全决策。

实际运维暴露该信号：管理员在日志详情只能看到规则标签与占位符，定位"具体哪段原文触发了规则"必须回到预览接口（mask test）复测，规则误报调优与审计链路断裂。需决定日志命中明细是否下发命中原文。

## 决定

翻转 2026-09-15 的「实施边界修订」，在日志命中明细中下发并展示命中原文 `original`（连同规则标签与占位符）：

1. `MaskMatch` 现产出 `{Label, Original, Placeholder}`，`RequestState.MaskMatches` 携带命中原文片段，SSE 概览与重连快照均下发。
2. 命中原文仅为命中片段（非整份请求体），可见性边界与日志详情/错误日志原有管理员可见性一致——不新增独立鉴权，复用既有管理员可见性。
3. 条数/字节上限对齐设计 §2.3.1：最多 128 条 / label 32 字符 / original 256 字符 / placeholder 64 字符 / 总 32KB。超限置 `RequestState.MaskMatchesTruncated` 截断标记，仅截断展示摘要，不影响实际替换。
4. 状态快照对 `MaskMatches` 做 `slices.Clone` 切片隔离，快照不受后续切片修改影响。
5. 错误日志落库存 `label + original + placeholder`，`normalizeMaskMatches` 归一兜底（坏 JSON/超限丢弃、不 redact 原文）；清洗仅限条数与字节数。
6. 前端 `MaskMatches` 组件展示规则标签、命中原文与占位符，截断时明确提示。

不变项：不把原始请求体写回 body、不改发往上游内容、不新增明文恢复接口、占位符替换与 `StreamRestorer` 逻辑全部现状保留。详细方案见 [docs/脱敏开发/07-日志详情命中明细.md](../../../../docs/脱敏开发/07-日志详情命中明细.md)。

## 备选方案

- **保留下发原文（本决定）** — 最强论据是审计与规则调优链路闭合，管理员在日志详情直接定位命中原文，无需回预览复测；采纳因为命中原文仅为片段（非整份请求体），可见性边界复用日志详情既有管理员可见性，不扩大攻击面到整份请求体。
- **维持不下发原文** — 最强论据是数据最小化、即使前端被改也无法展示；否掉因为审计链路断裂的实际成本已显现，且日志详情本身已是管理员可见域，原文片段的可见性未超出该域既有边界。
- **新增请求体明文恢复接口** — 最强论据是信息最全；否掉因为扩大攻击面、新增明文接口，与命中明细随状态流下发片段的方案相比收益不抵风险。

## 后果

- **收益**：管理员在日志详情直接看到命中原文片段，规则误报调优与审计不再回预览复测；命中明细随状态流实时下发，无需额外 API。
- **代价与已知上限**：命中原文片段进入 SSE 载荷与 ErrorLog 持久化，体积受 128 条 / 总 32KB 上限与逐字段截断约束；超限置 `mask_matches_truncated` 标记并截断展示摘要，不影响实际替换。重访信号：若命中原文片段的暴露面在审计场景被认定超出日志详情既有可见性边界，需重评是否回退到只存 label+placeholder 或引入独立鉴权。**该重访信号于 2026-09 审计中触发并已完成裁决**：审计再次列出「命中原文明文入库 error_logs」，评审维持原决策——命中片段入库属预期行为、不修，理由不变（命中片段非整份请求体，可见性域与管理员本机日志详情一致，有界归一兜底）；事实声明见 [docs/脱敏开发/07-日志详情命中明细.md](../../../../docs/脱敏开发/07-日志详情命中明细.md) 头部「审计复核」块。
- **取代关系**：本篇部分取代 [2026-09-15 立项笔记](./2026-09-15-log-detail-mask-match-detail.md) 的「实施边界修订：为什么不展示 original」一节——该节的事实（`MaskMatch` 不含 Original、前端不渲染原文）已被翻转。立项笔记保留为历史因果，其「问题」「决定」主体（接通命中明细到日志详情）仍成立。
