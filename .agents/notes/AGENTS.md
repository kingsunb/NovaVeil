# AGENTS.md — Agent Notes

Agent Notes 是 agent 写的 RFC：持久化的提案与决策记录，保留理由、备选、后果与验证。遵循 [文档标准](../../docs/README.md) 与 [Agent Note 规则](README.md)。

**每篇新 Agent Note 触发一次取代检查。** 搜活跃树里覆盖同一决策/机制的旧笔记，用 [`dsh-archive-agent-notes`](../skills/write-notes-like-deepseek/SKILL.md) 思路分类完全/部分取代，并在同一 PR 归档每个符合条件的 implemented 三元组。部分取代保持活跃并互链。

`archived/` 下的文件是冻结的历史快照：永不编辑，不当作当前权威。
